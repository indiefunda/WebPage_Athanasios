# Logo directions — Athanasios Desalermos

Five mark directions for the existing editorial wordmark. The live site has **not** been changed.

## Files

- `00-current.svg` — current triangle + dot, for reference
- `01-arch-light.svg` — open arch + clay point of light
- `02-ad-seal.svg` — ΑΔ monogram in a thin seal
- `03-intestinal-fold.svg` — continuous coil inspired by intestinal loops
- `04-lumen.svg` — thin ring with an opening and a point of light
- `05-open-delta.svg` — softened, open evolution of the current delta
- `logo-concepts.png` — contact sheet with header, favicon sizes and browser tab
- `preview.html` — live HTML preview (fonts served from `../../public/fonts`)

## Short read

1. **Arch + light** — the most site-native. Warm, architectural, not literal. Works at 16 px.
2. **ΑΔ seal** — the most personal/classic. Reads as a seal at 16 px, not as letters; best at 32 px+.
3. **The coil** — the strongest gastroenterology cue without anatomy. Best at 24 px+; use a simplified favicon if chosen.
4. **Lumen** — the most technological/favicon-first. Clean, but more generic.
5. **Open delta** — the safest transition from the current mark. At small sizes it can read as Λ rather than Δ.

## Recommendation

- **Primary:** `01-arch-light.svg` — it connects to the arch motif already used on the site and stays legible at small sizes.
- **If the doctor wants a clearer GI signal:** `03-intestinal-fold.svg` — the coil is abstract, modern and ownable.
- **If he wants a personal seal:** `02-ad-seal.svg` — but it needs a simplified 16 px variant.

No production assets, header or favicon were changed.
